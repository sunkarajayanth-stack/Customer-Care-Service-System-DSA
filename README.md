# Customer Service Management System – DSA Module

## Overview

This project is a **Data Structures and Algorithms (DSA) based simulation** of a Customer Service Management System. It demonstrates how common data structures and algorithms can be applied to manage customer service tickets efficiently. The program runs in the **terminal** and allows users to perform different operations through a menu-driven interface.

The system simulates real-world customer service workflows such as adding tickets, processing requests, storing records, and organizing data using various DSA concepts.

## Features

* Ticket processing using **Queue**
* Action history using **Stack**
* Ticket storage using **Linked List**
* **Bubble Sort** algorithm for sorting data
* **Linear Search** algorithm for searching elements
* Menu-driven terminal interface
* Simple and easy-to-understand implementation for academic demonstration

## Data Structures Used

1. **Queue** – Used to manage customer service tickets in a First-In-First-Out (FIFO) order.
2. **Stack** – Used to track and undo recent actions performed in the system.
3. **Linked List** – Used to store and manage ticket records dynamically.

## Algorithms Used

* **Bubble Sort** – Demonstrates sorting of elements.
* **Linear Search** – Used to find specific elements within a dataset.

## File Structure

CustomerServiceDSA.java  – Main program containing all DSA implementations

## How to Run the Program

### Step 1: Compile the Program

Open the terminal in the project directory and run:

javac CustomerServiceDSA.java

### Step 2: Run the Program

java CustomerServiceDSA
